# Doublons connus (guides de revue contractuelle)

`preparer` lit ce tableau : quand la ligne du jour figure dans la première colonne, il affiche la décision.
Ajoutez une ligne chaque fois qu'un sujet est écarté pour doublon, pour que le passage suivant le sache.

| Sujet de la ligne | Page proche | Décision |
|---|---|---|
| analyse de contrat | page /revision-contractuelle-ia/ | écarter (c'est la recherche visée par la page de l'outil) |
| revue de contrat | page /revision-contractuelle-ia/ | écarter (même raison) |
| relecture de contrat | page /revision-contractuelle-ia/ | écarter (même raison) |
| déséquilibre significatif | guide clause abusive entre professionnels | écarter si ce guide existe (même règle, article 1171 du Code civil et L. 442-1 du Code de commerce) ; sinon le traiter sous ce nom |
